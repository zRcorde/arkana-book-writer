# Install Guide — Arkana Book Writer

Step-by-step guide to install and use Arkana Book Writer on Windows. The app runs **100% locally** — none of your documents ever leave your machine.

## Step 1 — Install the prerequisites (one time only)

1. **[Node.js](https://nodejs.org/)** — needed for the application window (Electron).
2. **[Python 3.10 or newer](https://python.org/)** — during installation, check **"Add Python to PATH"**.

## Step 2 — Download the project

Download the repository's `.zip` (**Code → Download ZIP** button on GitHub) and extract it to any folder on your computer.

## Step 3 — Install the dependencies

Double-click **`Install Dependencies.bat`**. This script:

- checks that Node.js and Python are installed;
- runs `npm install` (Electron window dependencies);
- creates the `venv\` folder and installs the Python dependencies from `requirements.txt`.

Run this `.bat` again only if you update the project later.

## Step 4 — Start Arkana

Double-click **`Start Arkana.bat`**. Leave the console window open — it's what keeps the local server running. The app opens in its own window.

![Arkana's starting screen](assets/screenshots/01-import.jpg)

## Step 5 — Import your document

Drag a `.docx`, `.pdf`, or `.md` file into the import area, or click to select one.

## Step 6 — Pick a visual theme

On the **Style** tab, set the title and author, choose from the 40 available themes, and optionally upload a cover image. The live preview shows the result before exporting.

![Theme selection](assets/screenshots/02-themes.jpg)

## Step 7 — Export the e-book

On the **Settings** tab, click **Generate PDF** or **Generate EPUB**. The file is ready to download within seconds.

![Export complete](assets/screenshots/04-export.jpg)

Example cover generated by the app itself, *Cyber Future* theme:

![Cover generated with a dark theme](assets/screenshots/06-cover-cyberfuture.jpg)

## Common issues

| Problem | Solution |
|---|---|
| "Node.js not found" | Install it from [nodejs.org](https://nodejs.org/) and restart the terminal |
| "Python not found" | Install it from [python.org](https://python.org/), checking "Add to PATH" |
| App won't open / hangs during install | Delete the `node_modules` and `venv` folders and run `Install Dependencies.bat` again |
| PDF doesn't export (GTK error on Windows) | Run `venv\Scripts\python scripts\setup_gtk.py` and restart Arkana |
| Port already in use | Close the other Arkana instance or restart your computer |

See [README.md](README.md) for the full dependency list, manual Linux/macOS installation, and technical details.
